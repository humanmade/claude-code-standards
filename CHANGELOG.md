# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2025-01-09

### Added
- Initial release
- **hm-coding-philosophy** - Core engineering principles and code quality hierarchy
- **php-human-made** - PHP/WordPress coding standards (HM-Minimum)
- **javascript-human-made** - ES6+ JavaScript conventions
- **react-human-made** - React component standards and WordPress block editor patterns
- **css-scss-human-made** - CSS/SCSS standards with BEM and theme.json integration
- **altis-development** - Altis DXP local development and architecture guide
- **vip-development** - WordPress VIP environment and CLI guide
- **run-linters** - Linter discovery and execution utility
